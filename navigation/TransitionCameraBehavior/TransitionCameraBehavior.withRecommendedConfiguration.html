TransitionCameraBehavior.withRecommendedConfiguration

TransitionCameraBehavior.withRecommendedConfiguration constructor

TransitionCameraBehavior.withRecommendedConfiguration()

Creates a new instance of this class following the recommended configuration.

The default configuration sets FixedCameraBehavior for both HD and SD view. HD camera behavior uses 21 as FixedCameraBehavior.zoom and 75 as FixedCameraBehavior.cameraTiltInDegrees. SD camera behavior uses 17 as FixedCameraBehavior.zoom and 45 as FixedCameraBehavior.cameraTiltInDegrees. CameraHdTransition.minimumHdLengthInMeters is set to 500.
