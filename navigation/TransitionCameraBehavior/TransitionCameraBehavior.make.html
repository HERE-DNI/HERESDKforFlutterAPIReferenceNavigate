Creates a new instance of this class.

  • hdCameraBehavior Configuration for high-definition lane camera behavior. Used when HD lane data is available and provides detailed lane-level positioning. Must not be a TransitionCameraBehavior.

  • sdCameraBehavior Configuration for standard-definition lane camera behavior. Used as fallback when HD lane data is not available or during transitions. Must not be a TransitionCameraBehavior.

  • minimumHdLengthInMeters Minimum length of HD lane data required ahead to maintain HD camera mode. The camera transitions to SD mode when HD data availability falls below this distance.

Throws InstantiationException. InstantiationException when TransitionCameraBehavior.TransitionCameraBehavior().hdCameraBehavior or TransitionCameraBehavior.TransitionCameraBehavior().sdCameraBehavior is a TransitionCameraBehavior.
