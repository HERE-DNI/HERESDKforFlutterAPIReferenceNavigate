AutomotiveCameraBehavior

AutomotiveCameraBehavior class abstract

High-level camera controller for automotive navigation that delegates to either a TrackingCameraBehavior for following the vehicle or an AreaCameraBehavior for showing geographic regions.

Can also be deactivated via AutomotiveCameraBehavior.activeCameraType to release control to external code.

Configuration including animation durations, zoom policies, maneuver rules, and per-mode tilt/bearing/principal-point profiles is provided via a JSON string and validated at construction. The AreaCameraBehavior anchor is taken from the AutomotiveCameraBehaviorOrientationMode.modeNorthUp principal point in the configuration.

Note: This is a beta release of this feature and may contain bugs or exhibit unexpected behaviour. Related APIs are subject to change without a deprecation process.
