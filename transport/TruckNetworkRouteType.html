TruckNetworkRouteType

TruckNetworkRouteType enum

The type of Preferred Route.

Note: This is a beta release of this feature and may contain bugs or exhibit unexpected behaviour. Related APIs are subject to change without a deprecation process.

Values

bTripleRoute → const TruckNetworkRouteType

Applies if the preferred route is applicable to articulated vehicles with a second and third semi-trailer attached to the rear of the first semi-trailer, by means of a turntable. Single semi-trailers and delivery vehicles that comply to the same length, height, and width restrictions may use B-Triple routes.

max50 → const TruckNetworkRouteType

Applies if the preferred route is applicable to 50MAX vehicles.

hpmv → const TruckNetworkRouteType

Applies if the preferred route is applicable to HPMV (High Productivity Motor Vehicle) vehicles, which is a classification of heavy truck and trailer combination in New Zealand.

pbsLevel2a → const TruckNetworkRouteType

The preferred route belongs to PBS vehicle routes (Level 2A).

bDoubleHml → const TruckNetworkRouteType

Applies if the preferred route is applicable to a (b-double) with a HML (Heavy Mass Limit).

bDouble19 → const TruckNetworkRouteType

Applies if the preferred route is applicable to a (b-double) with a Length limit of 19m and with a general mass limit (GML).

bDouble23 → const TruckNetworkRouteType

bDouble26 → const TruckNetworkRouteType

bDouble26Hml → const TruckNetworkRouteType

bDouble27Dot5 → const TruckNetworkRouteType

bTripleHml → const TruckNetworkRouteType

Applies if the preferred route is applicable to a (b-triple) with a HML (Heavy Mass Limit).
