TruckNetwork

TruckNetwork class

Specifies a list of truck network route types, scoped to a specific country and optionally to a specific state within that country.

Note: This is a beta release of this feature and may contain bugs or exhibit unexpected behaviour. Related APIs are subject to change without a deprecation process.

countryCode ↔ CountryCode
Country code in ISO 3166-1 alpha-3 format in which the truck networks apply. Note: Not all countryCode and network combinations are supported. Unsupported country/network combinations will result in routing backend error. Refer to the Routing API documentation for the supported combinations and parameter requirements: https://docs.here.com/routing/reference/routing-api-v8-calculateroutes.
