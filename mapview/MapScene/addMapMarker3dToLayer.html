Adds a 3D map marker to the named layer.

The layer must have been created via MapScene.addMapMarker3dLayer before calling this method. A MapMarker3D can only belong to one layer at a time. If the marker is already added to any layer (including the default layer), it will not be added and the method returns false.

  • marker The 3D marker to be added to the named layer.

  • layerName The name of the layer to add the marker to.

Returns bool. true if the marker was added successfully, false if the layer does not exist or the marker is already part of another layer. Note: This is a beta release of this feature and may contain bugs or exhibit unexpected behaviour. Related APIs are subject to change without a deprecation process.
